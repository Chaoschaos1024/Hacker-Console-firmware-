## 📋 项目介绍

**Hacker Console** 是一款由本人设计的新一代手持终端，采用树莓派 B 系列作为核心主板。本仓库包含**全新一代固件（6.0+）**，带来革命性的系统状态监控与多页交互体验。
### 项目简介
	🖥️ 免驱动的 HDMI 屏幕，1024*600分辨率，支持触摸功能
	⌨️ HID 协议键盘，通过 USB 通信，即插即用
	🔧 独立 PCB 设计，键盘可自由替换
	📊 状态显示副屏，实时监控设备状态
	🔌 GPIO 引脚引出，方便外设扩展
	🏗️ 外壳设计开源，支持个性化定制

> 🔍 如果你对我的设计感兴趣，请在 **Bilibili** 上搜索 **"Hacker Console"**

### 🎨 全新多页设置界面
告别单一设置页，现在拥有**流畅多页切换**的现代化 UI：

- **Page 1** — 风扇转速设置
- **Page 2** — 屏幕背光设置
- **Page 3-6** — ws2812更能设置
- **Page 7** — 电池状态
- **Page 8** — 电源状态展示
- **Page 9** — 版本信息展示
- **Page 10** — 键盘信息展示
- **Page 11** — HDMI信息展示
- **Page 12** — 树莓派状态展示
- **Page 13** — 主控重启
- **Page 14** — 切换至程序更新模式
- **Page 15** — 主控状态

### ⚡ 一键进入更新模式
